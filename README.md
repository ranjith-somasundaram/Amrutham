# Nattarangu Finance

Live finance summary for the Amrutham Family 41st Anniversary event.

The page reads the event's Google Sheet through an Apps Script web app each time it opens, and every 60 seconds after that. All amounts are in AED. Phone numbers are never sent to the page.

- `index.html`: the app. The `DATA_URL` setting near the top of the script holds the Apps Script link.
- `poster.jpg`: event poster shown on the Overview.
